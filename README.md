# MCA Student Management System

The **MCA Student Management System** is a Python-based console application designed to manage student academic records efficiently. The system allows users to add, view, search, update, and delete student information through a simple menu-driven interface.

The application uses **Object-Oriented Programming (OOP)** concepts to represent student records and implements **file handling with JSON** to store and retrieve data permanently. It also automatically calculates students' total marks, percentage, and grade based on their subject marks.

## Key Features

* Add new student records
* View all registered students
* Search students using Student ID
* Update student information
* Delete student records
* Calculate total marks and percentage
* Automatically assign grades
* Store student data in a JSON file
* Load previously saved data when the application starts
* Simple and user-friendly menu-driven interface

## Technologies Used

* **Python**
* Object-Oriented Programming (OOP)
* Functions
* Lists and Dictionaries
* Conditional Statements
* Loops
* File Handling
* JSON

## Academic Information Managed

The system stores:

* Student ID
* Student Name
* Semester
* Python Marks
* DBMS Marks
* DSA Marks
* Operating System Marks
* Total Marks
* Percentage
* Grade

## Project Objective

The main objective of this project is to develop a simple student record management system while applying fundamental Python programming concepts in a practical application. It helps demonstrate knowledge of **Python programming, OOP, data structures, functions, and file handling**.
